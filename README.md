\# ejemplo-github-1



Repositorio de práctica para aprender a usar Git y GitHub en equipo.



\## Contenido



\- `README.md`: documentación del proyecto.



\## Requisitos



\- \[Git](https://git-scm.com/) instalado.

\- Una cuenta de GitHub.



\## Cómo empezar



1\. Clona el repositorio:



git clone URL\_DEL\_REPOSITORIO



2\. Entra a la carpeta:



cd ejemplo-github-1



3\. Antes de editar, trae los cambios más recientes:



git pull





\## Flujo de trabajo



\- \*\*Método tradicional:\*\* crea una rama (`git checkout -b feature/tu-tarea`), haz tus cambios y abre un Pull Request hacia `main`.

\- \*\*Método rústico:\*\* trabaja directamente en `main`, avisando antes a tu equipo si editas los mismos archivos.
